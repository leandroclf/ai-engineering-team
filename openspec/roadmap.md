# Roadmap

## M0 — Specification baseline
OpenSpec project, proposal, design, requirements and implementation plan.

## M1 — Codex-native MVP
AGENTS.md, core skills, workflows, quality gates and project adapter. No external API required.

## M2 — Stack packs
Java/Spring, Node/TypeScript, Python/FastAPI, AWS and Kubernetes capabilities.

## M3 — Repository automation
Bootstrap tooling, GitHub workflow, CI evidence and PR lifecycle.

## M4 — Multi-agent
Bounded specialist delegation, safe parallelism and reconciliation.

## M5 — Persistence
Session abstraction, resumable work, context budgeting and state/evidence ledger.

## M6 — Autonomous engineering loops
Event-driven intake and controlled iteration with explicit budgets, stop conditions and approval gates. Production/destructive actions remain governed.
